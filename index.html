Cotizador Solar Soinsolar - Aplicación Flutter Multiplataforma

📊 Resumen Ejecutivo

El Cotizador Soinsolar es una aplicación móvil y web que facilita la creación de cotizaciones para paneles solares. Permite llenar plantillas de Excel automáticamente, crear PDFs profesionales con la información del cliente, y personalizar imágenes directamente desde el celular o computadora.

📋 Carga Tu Plantilla de Excel

Sube tu propio archivo Excel con el formato de cotización. La app lo llena automáticamente con los datos que ingreses, sin perder el diseño original.

🧮 Cálculos Automáticos

🏗️ Arquitectura Técnica Destacada

🔧 Manipulación Excel Sin Decodificar

Innovador enfoque que trabaja directamente con bytes originales del archivo Excel, modificando el XML interno sin perder compatibilidad ni formato.

🎯 Custom Painter para Canvas

Sistema de dibujado de alto rendimiento que utiliza el engine de Flutter para renderizar figuras geométricas y trazos libres en tiempo real.

📦 Gestión de Assets Integrada

Carga eficiente de recursos desde assets (plantilla Excel, imagen de fondo) con fallback y manejo de errores robusto.
